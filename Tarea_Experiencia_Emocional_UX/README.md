# Análisis y rediseño de la experiencia emocional

Caso de estudio: pantalla `B-4-mapa.png.jpeg` de SuperOfertas Ecuador.

## Objetivo y tarea evaluada

La persona debe revisar el punto del mapa, confirmar que la dirección es correcta y avanzar al pago. Se analizan cinco momentos: ingreso, exploración, búsqueda/ajuste, selección y finalización.

## Hallazgos principales

- El contraste extremo y la jerarquía visual compiten con la tarea principal.
- El mapa no explica con claridad qué puede manipularse ni cuál es el punto seleccionado.
- El botón para guardar parece deshabilitado y compite con la acción “Omitir”.
- La urgencia comercial y el temporizador pueden aumentar presión en una tarea sensible.
- Falta retroalimentación clara al confirmar la dirección.

## Rediseño

Figma: https://www.figma.com/design/u7v5nFGtjdyHFBrtkbPgAU

El rediseño incorpora jerarquía clara, progreso legible, mapa con instrucciones, marcador seleccionado, campos editables, estado de confirmación, acción principal explícita y criterios básicos de accesibilidad.

## Estado de la validación

La inspección heurística y el rediseño están completos. La medición emocional con tres participantes reales permanece pendiente: la consigna prohíbe atribuir emociones no observadas. En `evidencias/pruebas_usuarios` se incluyen el guion, el consentimiento breve y la hoja de registro. La matriz Excel calcula promedios y comparación cuando se carguen las puntuaciones.
