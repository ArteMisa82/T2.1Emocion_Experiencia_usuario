# T2.1 – Emoción y Experiencia de Usuario

## Descripción del trabajo

Este proyecto corresponde a la asignatura de **Interacción Humano-Computador** y tiene como objetivo analizar y mejorar la experiencia emocional de los usuarios al interactuar con una interfaz digital.

El caso de estudio se centra en **SuperOfertas Ecuador**, específicamente en la pantalla de confirmación de la dirección de entrega durante el proceso de compra.

Se identifican problemas de usabilidad relacionados con la claridad de la información, la navegación, la selección de la ubicación y la retroalimentación del sistema. A partir de este análisis, se propone un rediseño de la interfaz aplicando principios de Interacción Humano-Computador para mejorar la comprensión, la confianza y la satisfacción del usuario.

El trabajo incluye el análisis de los momentos de interacción, curvas emocionales con datos simulados, una matriz de experiencia de usuario, el rediseño visual en Figma y un prototipo interactivo desarrollado en HTML.
