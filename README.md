# T2.1 — Emoción y experiencia de usuario

## Prototipo funcional de demostración

Abre `prototipo_final.html` en un navegador moderno. No requiere instalación, servidor ni `node_modules`.

El diseño toma como referencia la imagen «DESPUÉS — Rediseño en Figma» del informe del equipo: jerarquía clara, pasos del proceso, mapa ilustrativo, marcador único, edición de dirección, confirmación y acción principal descriptiva.

**Alcance:** mapa ficticio con movimiento de marcador, no geolocalización real; no realiza pagos ni guarda información en un servidor. La navegación externa es ilustrativa.

## Documentación

- `informe_final_completado.docx`: informe original ampliado con anexos de simulación y pendientes de pruebas reales.
- `informe_final_completado.pdf`: versión de consulta/entrega provisional.
- `curvas_simuladas.png`: trayectorias de tres perfiles modelados, no participantes reales.
- `prototipo_final.html`: interfaz HTML/CSS/JS demostrativa.

## Requisitos pendientes para la entrega académica

1. Reclutar tres participantes externos al grupo y obtener consentimiento.
2. Ejecutar la misma tarea en la versión original y el rediseño; registrar valoraciones -3 a +3, tiempos, errores y verbalizaciones reales.
3. Sustituir o separar las curvas y datos simulados de las conclusiones empíricas.
4. Documentar evidencias y validación de la matriz UX.
5. Registrar contribuciones auténticas de cada integrante mediante commits y Pull Requests.

**No presentar los datos simulados como resultados de pruebas con personas.**
